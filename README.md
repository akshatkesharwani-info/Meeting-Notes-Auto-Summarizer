# Meeting Notes Auto-Summarizer

Fine-tuned BART for dialogue summarization, plus a simple rule-based layer that pulls out action items.

## Problem Statement

Writing up meeting notes by hand takes forever. Zoom AI Companion auto-generates summaries directly from call transcripts. This project fine-tunes BART on dialogue-style text, then adds a keyword-based step that extracts action items ("will do X", "need to Y") from the generated summary.

## Dataset

[SAMSum Corpus](https://huggingface.co/datasets/knkarthick/samsum) — 14,731 messenger-style multi-turn dialogues, each with a human-written summary. Used as a free, license-friendly proxy for meeting transcripts.

## What It Builds

- A BART model fine-tuned to summarize multi-turn dialogue into a short paragraph
- A regex-based function that extracts action items from the generated summary
- A ROUGE evaluation against human-written reference summaries
- A saved, reloadable summarization model

## Results (from an actual training run)

| Metric | Value |
|---|---|
| Training dialogues | 14,731 |
| Training epochs | 3 |
| Final training loss | 1.18 |
| **ROUGE-1** | **0.392** |
| **ROUGE-2** | **0.196** |
| **ROUGE-L** | **0.302** |
| Training time | ~95 min on a free Colab T4 |

**Example summary generated by the model:**
> *"A wants to get a puppy for her son. She took him to the animal shelter last Monday and he really liked the one she showed him. He wanted to take it home right away and named it Lemmy after his dead hamster..."*

**Honest note:** the keyword-based action-item extractor returned an empty list on this particular example — the summary is past-tense narrative without explicit modal verbs ("will", "need to"), which the simple regex approach doesn't catch. A known, worth-mentioning limitation of the rule-based layer, not the summarization model itself.
